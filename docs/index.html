INVENTORY HUB / SYSTEM DESIGN

一个软件，两端共用

Electron 独立运行，Node.js 提供统一业务服务，手机通过局域网访问。以下六份图描述目标方案；SQLite 为建议选型，打印机兼容性尚待验证。

01 / ARCHITECTURE系统架构

入口、共用界面、业务服务、登录、存储与打印的职责关系。

 02 / LIFECYCLE物品状态流转

建档入库、出库、再次入库、废弃恢复及不可逆删除。

 03 / FRONTEND前端页面结构

统一导航下的档案、位置、扫码操作和管理设置。

 04 / RUNTIME运行时架构

手机、桌面进程、内置服务、持久化文件与本机打印边界。

 05 / WORKFLOW连续扫码与批量移位

选目标、连续采集、去重、预览确认、事务提交和失败处理。

 06 / PRINTING打印任务状态

任务领取、系统队列、明确失败、结果不明及人工核对。
